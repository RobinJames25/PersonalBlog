## 📖 Overview

This is a modern, responsive personal blog built with **React**. It features a distinct **"Slate & Blue"** color palette, a **Glassmorphism header**, and a grid-based layout for article showcases.

We transitioned this project from an initial anime-focused concept to a clean, professional portfolio piece designed to highlight technical writing and development skills.

## ✨ Key Features

* **🎨 Professional UI:** Custom "Slate & Blue" theme with a translucent (glassmorphism) navigation bar.
* **🔐 Admin Dashboard:** A dedicated `/admin` route for creating, editing, and deleting posts.
* **📧 Newsletter Integration:** Functional subscription form powered by **EmailJS** (no backend server required for emails).
* **📱 Responsive Grid:** CSS Grid layout that adapts perfectly to mobile and desktop screens.
* **🔌 API Integration:** Uses **Axios** to fetch posts from a custom Node.js backend (`/api/posts`).

## 🛠️ Tech Stack

**Frontend:**
* React.js (Create React App)
* Axios (HTTP Requests)
* EmailJS (Newsletter functionality)
* CSS3 (Custom Variables & Glassmorphism effects)

**Backend:**
* Node.js & Express
* Port: `5000` (API endpoint)
